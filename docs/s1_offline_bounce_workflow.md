# S-1 Offline Digital Multitrack Workflow

This document outlines the optimized, universal procedure for converting any standard multi-track MIDI file into a high-fidelity, mixed audio bounce using the hardware Roland S-1 synthesizer. 

## The Challenge
The Roland S-1 is a **monotimbral** synthesizer with a **4-voice polyphony limit**. It also features an internal **master bus compressor** that will aggressively "duck" or distort the audio signal if it is fed a loud USB playback signal while simultaneously synthesizing new audio. 

To overcome this, live overdubbing must be abandoned. Instead, we utilize an **Offline Digital Mixdown** architecture.

## The Strategy

### Phase 1: MIDI Analysis & Extraction
*Never attempt to dead-reckon complex MIDI timings.*
1. **Split the Tracks:** Run `split_midi_tracks.py` to explode the source `song.mid` into individual, isolated `.mid` files (e.g., `Track_1.mid`, `Track_2.mid`).
2. **Audition and Tag:** Use `audition_and_tag.py` to route these isolated tracks to the S-1 one by one using a clean, static patch (no LFOs, no Chorus, no Portamento). Tag each track with its function (e.g., "Bass", "Melody High", "Harmony").
3. **Verify Absolute Timing:** Do not mathematically trim silence off the beginning of extracted MIDI tracks. Respect the absolute chronological timeline of the original `.mid` file to guarantee synchronization later. Use `find_start_time.py` to confirm precisely when the very first note strikes. 

### Phase 2: Patch Assignment
1. Map each identified track to a specific Synth Patch generated by the project (e.g., Map "Bass" to `dw.init_who_bass(s1)`).
2. If the track relies heavily on overlapping portamento glides (and thus voice stealing), identify if the melody is doubled across octaves. If it is, *isolate each octave into its own track buffer* to ensure the 4-voice cap is never breached.

### Phase 3: Isolated Tracking Passes
Use `audio_looper.py` to orchestrate isolated recording passes.
1. Determine the absolute maximum duration of the song (e.g., 45.0 seconds).
2. For *every single track*, record a dedicated `.wav` file of that full duration, **starting from 0.00s**. 
3. *Crucial:* Do not play any audio back to the S-1 while recording. The S-1 must record each track in total silence to bypass its internal master compressor.

### Phase 4: Digital Mixdown
Once all layers have been individually recorded to their full absolute lengths (e.g., `track_1_bass.wav`, `track_2_melody.wav`), mix them in Python.
1. Use `soundfile` and `numpy`.
2. Ensure identical array lengths (trimming exact floating point discrepancies to the `min_len` of all arrays).
3. Apply digital mixing curves (e.g., `mixed_data = (bass_data * 1.5) + (melody_data * 0.8)`).
4. Perform a hard limit (`np.clip(mixed_data, -1.0, 1.0)`) to prevent digital clipping artifacts from floating point overflow.
5. Export to `master_mix.wav`. 

Because all `.wav` files were recorded starting from `0.00s` absolute time, stacking them digitally will naturally reconstruct the groove perfectly, without any need to program sample-accurate offsets.
